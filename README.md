# おぎココ学習塾・英語塾 公式サイト v2

静的HTML/CSS/JavaScriptで構成した公開用サイトです。Vercelにそのまま配置できます。

## 内容
- index.html: トップページ
- privacy.html: プライバシーポリシー
- styles.css: デザイン
- script.js: モバイルメニュー・控えめな表示アニメーション
- assets/images/: Web用に軽量化した実写画像
- ogp.jpg: SNS共有用画像
- favicon.png: favicon
- robots.txt / sitemap.xml: 検索エンジン向け
- vercel.json: Vercel設定

## 公開手順
1. このフォルダをVercelにデプロイ
2. Vercelで `ogicoco.jp` をDomainsに追加
3. Vercelが表示するDNSレコードをXServerドメインの「DNSレコード設定」に登録
4. `https://ogicoco.jp` と `https://www.ogicoco.jp` の表示・SSL・リダイレクトを確認
5. Google Search Consoleへサイトマップ `https://ogicoco.jp/sitemap.xml` を送信
